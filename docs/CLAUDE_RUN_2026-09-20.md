# Claude 実装記録 — 役割別オンボーディング（2026-09-20）

Issue #3「Claude実装: 最初に利用者/運転手を分岐し、登録情報から専用ホームへ遷移」の
**最初の成果物**として、以下を本リポジトリのルートアプリへ実装した。

- 役割選択（利用者 / 運転手）
- 利用者登録（表示名・国番号付き連絡先・任意メール・連絡言語・既定乗車地点・支払い希望・同意）→ 利用者ホーム（配車 / 車両確認 / 履歴 / 登録情報）
- 運転手3段階登録（本人・運転資格 → 車両・営業許可・名義人・営業範囲 → 確認書類・期限・同意）→ **審査待ちホーム**（ホーム / 依頼 / 運行 / 登録情報）
- 運転手は申請後も審査待ちのままで、受付開始・料金提示・迎車の操作はすべて無効。書類提出は承認ではない旨を画面に明記
- 登録途中の下書き自動保存と再読込後の復帰（この端末内のみ）
- URL直打ちで未登録のままホームへ入れないガード
- 端末保存に `approved` を書き込まれても読み込み時に審査待ちへ戻す（自己承認の禁止）

`docs/ROLE_SPLIT_AND_ONBOARDING.md` と `CLAUDE.md` のデザイン受入
（白/グレー基調・チャコール・控えめな緑・1.6px線画アイコン・44pxタッチ領域・絵文字/グラデーション/重い影なし・略地図はデモ表示と明記）に合わせ、
旧ルートアプリ（シアン基調・絵文字・混在メニュー）の `index.html` / `app.js` / `styles.css` を置き換えた。

## 起動方法

ビルド不要の静的ページ。次のどちらかで開く。

```bash
# リポジトリ直下で
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

または `index.html` をブラウザで直接開く（file:// でも動作する）。
スマホでの確認は、会話で共有した claude.ai の非公開プレビューページ（所有者のみ閲覧可）からも可能。

各登録フォーム右上の「サンプル情報を入力する」で架空のサンプル値を一括入力できる。
登録データは端末の localStorage のみに保存され、「登録情報」タブの
「この端末の登録データをすべて消す」でやり直せる。
